# ATIVA – Personal Wellbeing

**Your wellbeing. Your awareness. Your progress.**

ATIVA is an Android personal wellbeing application designed to help users monitor daily wellbeing patterns and develop healthier habits.

## Features

- **Daily Check-ins:** Record mood, sleep, energy, stress, activity, hydration, and focus.
- **Personal Insights:** Explore patterns in your daily wellbeing records.
- **Screen-Time Awareness:** Monitor phone usage and receive wellbeing alerts.
- **Health Tracking:** Support awareness of selected health and activity information.
- **Weekly Trends:** Review changes in recorded wellbeing patterns.
- **Notifications:** Receive reminders and screen-time alerts.
- **Privacy-Focused Design:** Designed for local wellbeing tracking without requiring an account.

## Download ATIVA

Download the latest Android APK from the Releases section of this repository.

**Note:** You may need to allow installation from your browser or file manager when installing the APK. Only install APKs from a source you trust.

## Installation

1. Download the APK to your Android phone.
2. Open the downloaded APK.
3. Allow installation from that source if Android requests permission.
4. Tap **Install** and open ATIVA.

## Important Disclaimer

ATIVA is intended for personal wellbeing awareness and educational purposes. It is not intended to diagnose, treat, or prevent any disease and does not replace professional medical advice.
